# 本轮定点修正审查

本轮仅改办公楼北面庭院立面及该处楼梯洞口；其余正面、外侧端面、穿孔屏风、车棚、入口与办公楼植物不改。

| 地点 | 原因与实施约束 |
|---|---|
| 办公楼北面 | 原楼板未开楼梯井；两跑楼梯穿过房间墙与完整楼板。取消无依据短横杆；保留22级/层的双跑楼梯，给1至4层楼板局部开洞；补左端内侧房间墙与封闭玻璃。 |
| 垃圾池 | 旧0.60m模数未实测。按约12×6格、相邻卷帘和人物尺度重新估计0.75m模数：宽9m、深4m、屋顶高4.79m。较上轮放大25%，约±15%，不能当作测绘尺寸。 |
| 小卖部连接处 | 保持两端规划锚点，补L形封闭围护与连续顶盖，连接垃圾池南侧与现有小卖部东端。内部功能与门窗缺乏证据，暂不虚构。 |
| 题石与报刊亭 | 本轮箭头终点朝实验楼通道侧。题石回到通道东侧台阶旁，保留原刻字；报刊亭移到对面宿舍端部。同侧加入铺地边、杂草、低矮叶片覆盖，避让3.5m通道。 |
| 东坡亭小路 | 采用规划图第1页已注册坐标，4m地形带中轴与14m斜段；照片明确标注2m净宽。第2页图像有平移，不能直接混用第1页原点。路线固定为北段—斜段—南段—前院连接。 |
| 亭子路口 | 图书馆路与塘连接路存在重合段、栏杆重复压入亭台。每段只保留一个路面，亭东口留接入支路，移除旧岸线的重复栏杆、旧土带、路面与接缝。 |
| 塘边植被与荷花 | 12株照片柳树从图书馆段移到东坡亭段，树根落在岸上，斜干朝水面。4株东坡树避让2m路面、2株亭旁柳树补连续土岸；水面、荷花排除道路、种植带和树根土岛。 |

验收使用同机位前后截图；办公楼其他立面及无关网格逐项比对；检查树根、路宽、石头及报刊亭碰撞、荷花与水岸一致性。
