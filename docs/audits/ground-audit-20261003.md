# 全校地面与路面审查报告

编制时间：2026-10-03T03:51:33.163706。编制阶段：修复前审查，模型尚未按本报告修改。

## 范围与依据

逐组查看14个素材目录的636张候选照片、39张索引图，并查看关键原图。范围包含全部27条道路、16块室外球场、1组跑道和内场、7块场地底面、14块规划绿地、4块规划铺地区域，以及所有建筑院落、入口、附房、亭子、桥头和临湖步道。内部照片不当作外部铺装证据。
建筑、场地和道路的米制位置及边界沿用《校园平面图-尺寸8-1.pdf》第2页现有配准：origin=(595,390)、0.60021m/图纸点。底图鸟瞰只作索引，不能作为尺寸标准。照片用于区分外观、接缝、标线及相邻关系。方砖尺寸、排水沟宽和局部标线间距属于比例估计，非实测。
运动场照片可确认红绿面层和磨损，不能仅凭照片判断是否为丙烯酸、EPDM或其他施工材料；报告统一称“彩色运动面层”，红跑道称颗粒跑道。
高：多个清晰实景可交叉确认；中：位置沿用图纸，材料有区域照片但未拍全段；低：缺少连续近景。低置信度项目按简化外观保留，并明确记录，不新增没有依据的文字和箭头。

## 优先修复事项

1. 校内水泥路和校外暂定沥青分开，消除“一种深色路面覆盖全部普通道路”。
2. 保持篮球场外围红色运动面层；清除模型中旧 sports.001 体育场地叠层，避免覆盖正确材质、重复白线和双层草坪。为操场南路恢复独立道路节点。
3. 草坪取消交替条纹；林下疏草土面、树池植土、器械场浅沙土与运动场草坪区分。
4. 补宿舍黄花纹方砖/红边圈、综合楼旧方砖、图书馆旧方砖、井前灰砖；补藤廊黄花纹瓷砖、入口白瓷砖和碎拼石路。
5. 仅补有照片依据的黄色中心线、实验楼前斑马线、食堂/办公楼/实训楼停车格。路面箭头：未找到可准确配准的依据，故本轮不新增。T03黄网格虽真实存在，但精确楼位未确认，不能猜位置。
6. 水泥板缝、灰石路缘、红砖边带、盖板沟、坡道入口过渡补齐；林下路边补疏草与落叶，保留上一轮350株植物与已修正根位。
