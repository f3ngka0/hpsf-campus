# 路沿、树池与微地形完成说明 · 2026-10-04

已完成本轮自主审查、修复与本地验证。详细同机位前后对比见[可视化报告](curb-terrain-review-20261004.html)。

## 实际修改

- 350条植物记录全部复核。95棵硬地树木补真实开口树池：切除铺装上下层，补土底、侧壁与13厘米宽实体池沿；方池主要1.4–1.5米宽。
- 182条自然根部或既有种植带记录保持自然形式，其中162处新增土面。69条灌木床、4处抬高花池保留，不给所有植物套水泥框。
- 新增59组实体路沿，总长约2970.6米，常规露高约12–16厘米。已有椰子大道的较高路沿保持；建筑入口、路口、桥头和东坡小路断开。
- 人行铺装有抬高侧壁和路口过渡，小卖部铺装回接现有门槛，开口树池贯通新旧各层。
- 12块绿地增加局部缓坡，主要7.5–16厘米高差；树根附近渐变回接。3291个原有低草叶面按新高度接回，保持形态和分布，原网格保留。

## 获取到的高程与限制

实际获取Copernicus GLO-30 N21E109原始GeoTIFF（32,097,276字节）和25×25区域样本，每格约30米。以OSM学校轮廓附近近似定位，尚未与规划图精确配准。

区域样本4.52–20.44米是含建筑、树冠的表面高程，不能解释成全校约16米地面落差。FABDEM下载站未连接成功，未取得裸地修正文件；现有规划图缺自然地形测量点。**没有取得可信的全校逐点地面起伏数据，本轮未把DSM强行套到模型上。**

因此采用实拍支持的局部高差，不虚构全校绝对标高和大尺度道路纵坡。所有尺寸为保守比例估计，后续取得测量点后可继续校准。

## 保留与验证

58个建筑、350条植物记录、27条道路全部保持坐标和形状；94个无关网格逐项完全保留。水面、桥拱、球场涂层、跑道和全部标线一致。办公楼指定立面、垃圾池连接、题石、报刊亭和东坡岸路等上一轮修正保留。

实际导出铺装检查8750个低处三角面，95个树池内残留铺装盖板为0。39项针对性检查、生产构建通过；11个最终视角无浏览器运行错误。编辑器道路重建仍保留树池开口，行走高度与坡面一致。
