# 路沿、树池与校园高差审查 · 2026-10-04

本轮覆盖全部 350 条植物记录、27 条道路及全部绿地。冻结当前完成版作为基线，再进行增量修改。

## 发现与修复决定

|问题|依据|修复|
|---|---|---|
|硬地上的树直接穿过完整铺装|当前近景、宿舍 D09/D10，综合楼 C14/C48，小卖部实拍|95 个独立树池；真正切除底层与上层铺装，补土面、侧壁、13厘米宽池沿|
|绿地、树林根部缺少种植接触面|办公楼 O06/O09/O15，小树林 G31/G40，东坡小路实拍|自然土面与已有种植带；不把树林统一做成水泥方框|
|多数灰色路缘仍近似平面|办公楼 O10/O11、宿舍 D05/D09/D10、校道和小卖部实拍|有侧壁的路沿；常规露高约12–16厘米，交叉口和建筑入口断开|
|绿地全部平齐，路面与种植区没有层次|办公楼 O06/O09、学校卫星图、已配准规划图|局部绿地作7.5–16厘米缓坡，增加抬高人行铺装；固定建筑、球场、桥、水面|

## 高程数据实际获取结果

已下载 Copernicus GLO-30 的 N21E109 原始 GeoTIFF（32,097,276字节）。以 OpenStreetMap 学校轮廓附近的 WGS84 109.1974°E、21.6763°N 为**近似区域定位**，提取25×25格、约750米区域样本。它与规划图尚无精确地理配准，不能作逐栋地面标高。

样本表面高程 4.52–20.44 米，相邻30米格出现数米跳变。产品官方明确它是包含楼房、设施和树冠的 DSM。**不能把这约16米差值解释成校园地面落差，更不能直接弯曲模型。**

另外查询了 Bristol FABDEM 去建筑、去树高产品，当前下载站连接失败/超时，未取得区域裸地高程。本地卫星图没有可用GPS配准，规划PDF第一页有建筑+0.5米台基说明，没有可用自然地形等高线或测量点。

因此本轮不虚构整个校园的绝对标高和大尺度坡向。落实照片可支持的路沿、树池、人行铺装、绿地局部高差。局部尺寸是保守比例估计，不是测绘结果；保留原始数据以便未来有实测点时继续校准。

## 防止现有建模变形的约束

保持全部建筑与树的位置和轮廓；完整保护跑道、球场、桥拱和所有水面。新增池沿不得封住建筑入口、路口或东坡2米小路。树池要切穿各层硬铺装，不能用土色贴片遮盖。绿地坡面在道路、建筑、树根及原有景物附近平顺回接。
