# 本轮设施修正完成说明（2026-10-04）

已完成三处设施、两块题石迁移，以及黄圈区域的七个粗模块。实际效果可查看同目录 `facilities-review-20261004.html`。

## 已实施

- 垃圾池放在黑板宣传栏末端，入口朝校道。补出开放前脸、深色贴砖檐口、侧墙砖缝、后墙提示牌、低位收集斗、蓝色挡板、左右缓坡及混凝土前坪。
- 小卖部从原有独立小平房改为宿舍底层连续商铺立面。以 PDF 的东段 43.5m 为参照，补卷闸门、红色长招牌、黄色饮料广告面、雨檐、饮料柜和铺砖人行带；商铺实际范围与十个开间为推断。模型 0.48m 深度仅是立面厚度，不能当作室内进深。宿舍上层仍保留现有模型。
- 两块题石及原有字样、底座整体移至综合楼东侧校道西边；报刊亭放到对面宿舍前，朝向校道。亭体补绿色正面及侧面卷帘、金属框架、邮政字样和双层平檐。
- 黄圈区域补两栋多层体量、四间连续低层附房和一条南侧长附房。暂按旧底图 6F / 8F 和一层附房处理，不虚构精细门窗。西南绿色斜线地块保留为空地。
